# Support matrix

Tiers (ADR-012): **Verified** = executed tests or a recorded run; **Build-only** = compiles or publishes,
not executed; **Planned** = not implemented. Nothing here is Verified unless the evidence column says how.

Release status: [README](../README.md#status).

`maui-windows` 10.0.20, PostgreSQL 17.6 (portable build, local), WebView2 154.
Partial run 2026-10-05 (0.1.1 work), Windows 10 Enterprise 10.0.19045 x64, .NET SDK 10.0.401, no PostgreSQL:
`dotnet test src/Tests/Bsync.Tests -c Release` (510 tests) 20 consecutive times with `DOTNET_PROCESSOR_COUNT` 1 or 2
